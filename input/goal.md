This repository is created to evaluate, compare and pick the best way to keep visibility on what resources are used for in agentic workflows for development tasks.

This include tokens and LLM inference costs, compute resources used, and time to delivery.
Ideally we need to track how successfuly the task was solved.

Subyard profile will provide reference implementation, but the goal is this solution should be usable in most agentic workflows without Subyard. Like typical devcontainer where opencode/codex/claude are working.

We need to provide simple clear and reliable metrics, so humans can see where is the buttleneck.
